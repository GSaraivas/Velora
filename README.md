# 🌸 VELORA — Floricultura Premium

### Flores que expressam sentimentos. Design que transforma experiências.

A **VELORA** é uma landing page premium desenvolvida para uma floricultura conceito, combinando elegância, sofisticação e tecnologia para criar uma experiência digital única.

O projeto explora uma identidade visual refinada, composições florais cinematográficas, animações fluidas e uma interface minimalista que transmite a delicadeza e a exclusividade de uma marca de luxo.

Mais do que apresentar flores, a proposta é transformar a navegação em uma experiência visual envolvente.

---

## ✨ Sobre o Projeto

A VELORA nasceu com o objetivo de demonstrar como uma floricultura pode fortalecer sua presença digital por meio de um site moderno, elegante e estrategicamente desenvolvido.

Cada elemento foi pensado para valorizar os arranjos florais, transmitir emoções e proporcionar uma navegação agradável em diferentes dispositivos.

O projeto combina **design editorial, fotografia cinematográfica, interatividade e animações modernas**, criando uma experiência premium do primeiro contato até a exploração dos produtos.

## 🚀 Tecnologias Utilizadas

- **HTML5** — Estrutura semântica e organizada.
- **CSS3** — Estilização personalizada, responsividade e efeitos visuais.
- **JavaScript (ES6+)** — Interatividade e funcionalidades dinâmicas.
- **GSAP (GreenSock Animation Platform)** — Animações fluidas e transições cinematográficas.

## 🎨 Identidade Visual

A identidade da VELORA foi desenvolvida para transmitir sofisticação, delicadeza e exclusividade.

**Direção visual:**
- Estética floral premium e minimalista.
- Tipografia editorial elegante.
- Composições com destaque para os arranjos florais.
- Iluminação cinematográfica e tons naturais.
- Contrastes sofisticados e utilização estratégica de espaços.
- Microinterações e transições suaves.

A proposta visual aproxima o universo das floriculturas da linguagem de marcas contemporâneas de luxo.

## 🌷 Funcionalidades e Destaques

### Hero Cinematográfico
Seção principal com composição floral de destaque, tipografia elegante e elementos visuais que criam uma primeira impressão marcante.

### Animações com GSAP
Movimentos suaves, transições refinadas e efeitos de entrada que tornam a navegação mais dinâmica e envolvente.

### Experiência Responsiva
Interface adaptada para diferentes resoluções, proporcionando uma experiência consistente em computadores, tablets e smartphones.

### Design UI/UX
Organização visual, hierarquia tipográfica e navegação intuitiva, priorizando estética e usabilidade.

### Apresentação Premium
Elementos visuais desenvolvidos para valorizar os produtos, reforçar a identidade da marca e transmitir exclusividade.

## 📱 Responsividade

O projeto foi pensado para oferecer uma experiência visual consistente em diferentes dispositivos:

- Desktop
- Tablet
- Smartphone

Com ajustes de layout, tipografia, espaçamentos e composição visual conforme o tamanho da tela.

## ⚙️ Como Executar

**1. Clone o repositório**

```bash
git clone https://github.com/gsaraivas/VELORA.git
```

**2. Acesse a pasta do projeto**

```bash
cd VELORA
```

**3. Execute o projeto**

Abra o arquivo `index.html` no navegador ou utilize a extensão **Live Server** no Visual Studio Code.
